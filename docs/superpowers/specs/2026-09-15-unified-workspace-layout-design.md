# 统一工作台布局设计

## 目标

将抖店助手现有的店铺、营销、商品、视频和记录页面统一为桌面工作台布局：固定侧边栏负责导航，每个页面只展示本栏目任务；主区使用一致的路径、标题、操作、概览和任务卡片节奏。

参考 Cockpit Tools 的信息层级与卡片密度，不复制其品牌、深色横幅或 AI 账号管理内容。

## 全局框架

- 应用壳固定为浏览器视口高度；浏览器页面不产生全局纵向滚动。
- 左侧栏固定宽度，按店铺、营销、商品、视频、记录分组；当前菜单有清晰高亮。侧栏内容超高时仅侧栏内部滚动。
- 主内容区在每一页使用同一顺序：面包屑、标题与说明、主要操作、页面专属概览或操作卡、结果或历史列表。
- 主区使用受控的最大阅读宽度与一致的间距；不将内容强行拉伸至边缘，也不留下大面积空白。
- 窄屏时隐藏侧边栏，并将同页双栏任务卡堆叠为单列；内容区可内部滚动。

## 页面边界

### 店铺

- 店铺列表：店铺数量、待处理任务、今日执行等概览；下方仅显示店铺列表和店铺操作。
- 账号状态：账号授权与状态信息。
- 不展示营销、商品或视频任务。

### 营销

- 建立优惠券：当前活动概览、创建入口、最近活动列表。
- 建立新人礼金：对应新人礼金任务、状态和记录。
- 不展示店铺表格或视频处理区域。

### 商品

- 商品搜索：搜索条件、结果列表与查看入口。
- 标题检查：标题输入、检查结果与历史记录。
- 不展示营销或视频处理内容。

### 视频

- 视频抽帧：源视频上传与参数为一个任务卡；输出预览、进度和下载为另一个任务卡；处理记录只显示视频任务。
- 两个视频预览采用正常 16:9 比例；预览、进度和元数据保留清晰间隔，不能相互覆盖。
- 目标帧率、输出格式和开始处理集中在源视频卡内；下载按钮集中在输出卡内。

### 记录

- 表格模板与执行记录均展示各自的列表、筛选或空状态。
- 执行记录可以按任务类型展示视频、营销和商品任务，但不把任务操作混入列表页。

## 视觉规则

- 继续使用现有蓝色作为唯一操作强调色、浅蓝灰背景和白色内容卡；不引入新依赖或新的设计系统。
- 外层工作区圆角略大于内部控件；卡片边框轻、阴影克制。
- 标题、说明、数据、状态标签形成三档层级；数据使用等宽数字呈现。
- 操作入口最多一个主要按钮，其余为次级按钮或文字操作。
- 未选择视频、无店铺、无结果等状态提供下一步操作，而不是空白区域。

## 验收标准

1. 点击侧边栏后，主区只呈现该菜单对应的内容。
2. 所有现有页面共享统一导航、标题和卡片间距，且保持现有功能可用。
3. 视频抽帧页的预览、进度和元数据不重叠，预览为 16:9。
4. 宽屏没有浏览器级滚动条；窄屏可正常使用单列布局。
5. 页面测试、类型检查、生产构建和样式差异检查通过。
