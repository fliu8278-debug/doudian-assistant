# 视频抽帧界面设计

## 目标

在“视频 > 视频工具 > 视频抽帧”中提供一个本地视频到新视频的处理界面：用户导入本地 MP4，设置更低的输出帧率，保留原视频时长和声音，完成后预览并下载新的 MP4。

本阶段只实现界面和交互状态，不接入 FFmpeg 或实际视频处理。

## 页面结构

页面标题为“视频抽帧”，辅助说明为“降低视频帧率，保留原时长和原声音”。内容区域固定为左右两栏。

### 左栏：源视频与参数

左栏是唯一的输入与操作区，依次包含：

1. 本地 MP4 拖放/选择区，文案为“导入本地视频”和“支持 MP4”。
2. 源文件信息行，显示所选文件名；未选择时显示“未选择视频”。
3. 原视频预览区。
4. 抽帧设置：目标帧率数字输入，默认 15 FPS；输出方式显示为“MP4 · 保留原声”；提示“视频播放速度保持不变”。
5. 主操作按钮“开始处理”。未选择视频时按钮不可用。

### 右栏：输出视频

右栏不包含任何导入或处理参数，仅展示产物与状态，依次包含：

1. 标题“输出视频”和“下载视频”按钮；处理完成前下载按钮不可用。
2. 新视频预览区。未生成前显示空状态。
3. 处理进度：百分比、进度条与三个顺序阶段“读取视频 → 重新编码 → 生成 MP4”。
4. 输出信息：输出时长、输出帧率、输出大小。
5. 底部状态说明；初始状态为“等待开始处理”。

## 交互状态

- 选择 MP4 后，左栏更新文件名和原视频预览；右栏仍为等待状态。
- 修改目标帧率只更新左栏参数。
- 点击开始处理后，右栏进入处理态，并依次强调三个处理阶段。
- 完成后，右栏显示新视频预览、输出信息，并启用“下载视频”。
- 本阶段以本地模拟状态呈现上述流程；实际 FFmpeg 和文件保存由下一阶段接入。

## 边界与可访问性

- 不显示图片帧、图片网格、ZIP 或图片下载入口。
- 左栏只包含上传和处理；右栏只包含输出、进度和下载。
- 使用原生文件输入与语义化按钮；禁用按钮须保留可读原因或状态说明。
- 窄窗口下两栏改为上下排列，源视频与参数在前，输出视频在后。

## 验收

1. 侧边栏“视频抽帧”打开本页。
2. 页面视觉与既有浅蓝灰背景、白色面板及蓝色主操作风格一致。
3. 上传、帧率输入、开始处理、进度与下载状态能在本地 UI 中完整演示。
4. 页面不暗示图片导出；下载动作明确指向处理后的视频。
