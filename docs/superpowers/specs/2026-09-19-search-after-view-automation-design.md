# 看后搜配置独立自动化流程

## 目标

新增一个可被后续 UI 调用的独立流程，用已登录的抖店浏览器为一条看后搜视频配置承接商品和自定义搜索词。

## 输入与输出

- 输入：店铺登录档案、1 至 3 个自定义搜索词、可选款号和可选是否提交。
- 未提供款号时：在“待配置、近30天、全部自营账号、挂车全部”的结果中寻找首条标题中带 `款号-颜色码` 的视频；无款号视频跳过。
- 输出：配置的视频 ID、识别到的款号、选中的商品 ID、主推商品 ID，以及是否已提交。

## 浏览器流程

1. 打开搜索运营页，并应用固定筛选；不刷新整页。
2. 定位目标视频，打开“立即配置”。
3. 按款号搜索全部商品链接，全部选中，包括国补链接。
4. 如果同时存在非国补链接，设第一条非国补链接为主推；否则保留平台默认主推。
5. 填入输入的 1 至 3 个看后搜词，验证词数与承接商品数。
6. `autoSubmit` 为真时点击“立即提交”；成功后关闭当前网页标签，不关闭已登录浏览器。

## 错误处理

- 未登录、筛选页未就绪、找不到带款号视频、商品搜索无结果、没有可选商品、词数无效和提交后仍停留在配置页都返回明确错误。
- 自动化失败时保留当前页面并返回明确错误，不写入截图文件。

## 测试

- 先为款号解析与搜索词验证写单元测试。
- 再为流程中的商品选择和主推规则添加 Playwright 页面替身测试；真实店铺仅用于人工验收。

## 非目标

- 本阶段不增加 UI、批量队列、数据库表或导入模板。
