# 侧栏一级/二级菜单设计

## 目标

将当前平铺的侧栏功能整理为可折叠的一级分类和二级入口，降低功能增多后的视觉密度，同时不改变现有页面入口、图标或业务行为。

## 交互结构

- 一级分类：店铺、营销、商品、视频。
- 二级入口：沿用当前分类下已有按钮。
- 点击一级分类标题切换展开/收起。
- 当前页面所属分类始终保持展开，避免用户看不到当前入口。
- 页面切换只改变现有 `page` 状态，不新增路由或业务状态。
- 展开状态保存到浏览器本地存储；读取失败时使用默认展开状态，不影响启动。

## 视觉规则

- 复用现有 `sidebarNav`、`sidebarNavGroup` 和 `sidebarNavItem` 样式体系。
- 一级标题使用现有颜色和字号，增加展开/收起指示图标。
- 二级入口保留当前 SVG 图标和选中态，只增加层级缩进与可点击区域。
- 设置、表格模板、执行记录保留在底部区域，不纳入上述四个一级分类。

## 默认状态

- 首次使用：四个一级分类全部展开，保证现有用户不丢入口。
- 再次打开：恢复上次保存的展开状态。
- 当用户直接进入某个二级页面时，自动展开对应一级分类。

## 验证

- 组件测试：检查四个一级分类、二级入口、展开/收起按钮和当前分类自动展开。
- 构建检查：运行完整测试、类型检查、生产构建和 `git diff --check`。
- 不触碰优惠券、店铺、更新和 RPA 业务逻辑。
