# 看后搜配置 UI 设计

## 目标

在现有抖店助手 React 工作台中新增“看后搜配置”页面，并在“商品”侧边栏分组中提供入口。第一阶段实现可交互的本地演示 UI，不调用真实店铺接口；后续可复用已有 RPA 流程接入真实执行。

## 页面结构

- 侧边栏“商品”分组新增“看后搜配置”，与“商品搜索”“标题检查”并列。
- 页面标题为“看后搜配置”，面包屑为“商品 / 看后搜配置”。
- 顶部显示当前店铺、刷新按钮和本地演示提示。
- 筛选卡包含：配置状态、指标周期、发布来源、是否挂车、查询、重置。
- 摘要卡显示待配置、审核中、已完成和总视频数。
- 视频列表显示标题、款号、视频 ID、发布时间、配置状态和“立即配置”按钮。

## 配置交互

点击“立即配置”打开右侧配置抽屉，包含：

1. 视频摘要和款号。
2. 承接商品选择区：搜索商品、全选、国补标签、主推标识；默认选中演示商品，非国补商品为主推。
3. 看后搜词输入区：最多三个词，输入后以标签展示；预置“斯凯奇纵云”“斯凯奇速锋”“斯凯奇男鞋”，允许编辑。
4. “立即提交”和“取消”按钮。

提交演示数据后关闭抽屉，将当前视频状态改为“审核中”，并在执行记录中追加一条本地记录。失败时保留抽屉并显示错误提示。

## 实现边界

- 复用 `App.tsx` 的页面路由、侧边栏分组展开逻辑和现有 CSS 变量/组件风格。
- 新增页面组件和最少量样式，不引入新的 UI 依赖。
- 演示数据使用组件内常量与 React state；不写入真实店铺、不触发浏览器自动化。
- 为页面路由、筛选状态、抽屉提交和搜索词标签补充最小组件测试。

## 验收标准

- 左侧“商品”分组可看到并打开“看后搜配置”。
- 页面视觉风格与现有软件一致，列表、筛选、摘要和抽屉在本地可见。
- 能完成一次从筛选到打开配置、修改三个搜索词、提交并显示“审核中”的演示流程。
- `npm run typecheck`、相关 Vitest 测试和 `npm run build` 通过。
