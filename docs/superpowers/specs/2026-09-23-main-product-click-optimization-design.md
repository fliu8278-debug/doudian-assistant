# 设置主推点击优化设计

## 目标

缩短商品卡“设置主推”按钮已经出现后，自动化触发点击所花的时间，同时保持现有商品选择、主推成功确认和错误处理不变。

## 设计

- 继续等待目标商品 ID 对应卡片中的“设置主推”按钮可见，确保没有点错商品。
- 按钮可见后，通过该元素原生的 `HTMLElement.click()` 触发点击，替代 Playwright `click({ force: true })` 的动作等待。
- 点击后继续等待页面出现“已成功设为主推品”；没有出现仍按现有逻辑报错。
- 不调整商品搜索、商品勾选、确定、填词、提交或翻页流程。

## 验证

- 回归测试证明点击助手等待按钮可见后调用原生点击，而不调用 Playwright 动作点击。
- 现有看后搜测试、类型检查全部通过。
- 使用真实页面复测，确认主推成功提示仍出现，并记录点击阶段耗时。
