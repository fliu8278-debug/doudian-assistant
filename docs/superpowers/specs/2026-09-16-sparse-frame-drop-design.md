# 稀疏抽帧设计

## 目标

将现有“固定降低输出帧率”的视频处理替换为稀疏删除画面帧，并继续输出可预览、可下载的 MP4 视频。

## 用户可选模式

- 随机抽帧：随机删除用户填写数量的画面帧，默认 1 帧。
- 间隔抽帧：每隔用户填写的秒数删除 1 帧。
- 两个模式均保留原音频、分辨率和原始时间线；不导出静态图片，不将整段视频统一转换为固定 FPS。

## 界面

- 移除“目标帧率”输入，改为“抽帧方式”双选项。
- 随机模式显示“随机删除 N 帧”。
- 间隔模式显示“每隔 N 秒删除 1 帧”。
- 输出信息显示处理方式，不再显示“输出帧率”。

## 处理方式

- 使用随应用打包的 `ffprobe` 读取源视频帧率和时长，用于计算安全的帧位置。
- 随机模式在首尾保护范围外选择不重复帧号。
- 间隔模式根据源帧率把秒数转换为帧间隔，选择对应帧号。
- FFmpeg 使用 `select` 视频过滤器排除这些帧，并保留原始时间戳；音频映射保持不变。输出为 H.264 + AAC MP4。
- 删除的帧只造成对应时刻的画面间隔，不会把整段视频降为固定低帧率，也不造成音视频失同步。

## 验证

- 单元测试覆盖两种模式的参数验证和 FFmpeg 过滤器。
- API 测试覆盖模式与数值的请求传递。
- 组件测试覆盖两种模式字段与输出说明。
- 以本地 MP4 真实处理一次，检查输出仍为 H.264/AAC、可预览且时长保持原值。
