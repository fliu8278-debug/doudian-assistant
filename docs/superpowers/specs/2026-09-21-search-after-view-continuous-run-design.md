# 看后搜连续执行与立刻暂停设计

## 目标

“开始自动配置”启动后，持续处理筛选结果中的待配置视频；每成功提交一条，继续寻找下一条。用户点击“暂停任务”时，立刻中断当前浏览器动作，不提交当前条，也不关闭登录浏览器。

## 方案

- 后端为每个正在运行的看后搜任务保存一个 `AbortController`，开始接口立即返回任务 ID，实际浏览器流程在后台运行。
- 自动化在任务启动时于同一登录上下文中打开一个独立任务页。列表文字没有六码款号时直接跳过；列表有款号时，点击“立即配置”后必须在“设置视频标题”中读取到相同款号，才选商品、填词、等待 3 秒并提交。提交后保留该页并继续下一条，任务结束或暂停才关闭任务页，店铺原有页面保持打开。
- 成功和失败的视频 ID 都记录为已处理；因此列表刷新滞后时不会重复选中同一条。单条异常时只关闭当前弹窗回到同一列表页，不重新打开或导航浏览器。
- 暂停接口触发任务的 `AbortController`，关闭独立任务页，并等待该页关闭后再返回 `paused`。因此不会再启动当前条的提交动作，登录浏览器及上下文保留。
- 前端按任务 ID 查询状态，显示当前款号、已提交数量、错误数量和最新记录；运行时显示“暂停任务”，暂停后显示“已暂停”，可再次点击“开始自动配置”创建新任务。

## 状态与错误

- 状态仅有 `running`、`paused`、`complete`、`failed`。
- 只有所有分页均没有满足“列表和标题款号一致”的待配置视频时，任务才以 `complete` 结束；无款号或款号不一致视频保持跳过。
- 已定位到的视频配置异常记录为错误并跳过该视频后继续下一条；登录失效或暂停会停止整个任务。

## 验收

- 一条提交后任务仍保持 `running` 并继续下一条。
- 点击暂停时，当前条不提交，接口和界面最终显示 `paused`。
- 不关闭店铺登录浏览器；重新开始可继续处理剩余待配置视频。
