# 视频抽帧侧边栏入口设计

## 目标

为抖店助手增加视频工具的导航入口，为后续视频抽帧功能预留清晰位置。

## 范围

本次仅新增导航和对应占位页面，不实现视频选择、抽帧、导出或后端处理。

## 导航结构

在现有“商品”和“记录”之间新增可折叠的一级分组：

```text
视频
  视频工具
    视频抽帧
```

点击“视频抽帧”后，主区域切换到视频抽帧占位页，说明该功能正在建设中。导航项使用现有侧边栏按钮样式和激活状态，无需新增依赖、路由库或后端接口。

## 组件与状态

- 在 `App.tsx` 的页面联合类型中增加 `videoFrameExtraction`。
- 复用 `openGroups` 管理“视频”分组的展开状态。
- 复用 `NavGroup`、`navClass` 和现有主区域条件渲染。
- 占位页保持为本文件内的最小 React 组件，不新增文件。

## 错误处理与测试

此变更不读取文件、不调用接口、也不引入新输入，因此无新增错误分支。现有 TypeScript 检查应覆盖页面类型和组件引用。
