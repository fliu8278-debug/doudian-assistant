# 更新下载进度条

## 目标

将软件更新弹窗中的浏览器默认进度条替换为状态化进度组件，使用户明确知道更新处于哪个阶段、完成比例及下载量。

## 已确认的界面

采用用户确认的右侧方案：

- 标题下保留简短说明。
- 进度区域顶部显示当前阶段“下载更新包”和大号百分比。
- 使用圆角浅色轨道与抖店助手现有蓝色填充条。
- 下载事件提供大小时，显示“已下载 / 共计”；缺少大小时不显示该行。
- 底部显示三个阶段：检查更新、下载更新包、重启安装。
- 下载完成后仍使用现有“更新已准备好 / 重启更新”流程。

## 数据与边界

- 继续使用现有 `download-progress` 的 `percent`、`transferred`、`total` 数据，不新增接口或依赖。
- 百分比取整并限定为 0–100。
- 阶段仅反映已有更新状态，不伪造安装进度。
- 使用语义化进度文本与 `aria-live`，便于屏幕阅读器获取状态变化。

## 验证

- 组件测试验证下载状态会渲染自定义轨道、百分比和阶段文案。
- 当无文件大小时不渲染下载大小行。
- 完整测试、类型检查和 Windows 打包通过后发布新版本。
