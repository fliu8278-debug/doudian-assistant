# 抖店助手

抖店助手是一款本地桌面工具，帮助店铺运营人员批量处理优惠券、新人礼金和视频相关任务。任务通过已登录的店铺浏览器执行，界面会按项目和款号显示进度、结果及失败原因。

## 主要功能

- **店铺管理**：管理店铺与登录状态，为不同店铺保留独立的本地浏览器配置。
- **批量建券**：导入 Excel 或 CSV 表格，建立涨粉券、商品优惠券和国补优惠券，并按款号选择商品。
- **新人礼金**：导入款号和礼金金额，逐条填写并提交新人礼金任务。
- **看后搜配置**：按待配置视频逐条关联承接商品、设置主推商品和看后搜词。
- **视频抽帧**：批量处理 MP4 视频，支持随机或按间隔抽帧，并保留原声与原视频时间线。
- **执行记录**：集中查看各项目的任务进度、处理款号和失败原因。

## 本地运行

需要 Node.js 24 或更高版本。安装依赖后，可启动本地开发页面：

```bash
npm install
npm run dev
```

前端运行在 `http://127.0.0.1:5173`，本地服务会同时启动。启动桌面应用：

```bash
npm run app
```

首次使用时，先在软件中选择店铺并完成登录，再导入对应任务的表格。

## 常用命令

```bash
npm test
npm run typecheck
npm run build
npm run dist:win
```

`dist:win` 用于生成 Windows 安装包。

## 本地数据

数据库、浏览器配置和任务运行数据保存在本地 `data/` 目录。该目录已被 `.gitignore` 排除；请勿将 Cookie、账号信息或其他店铺敏感数据提交到仓库。

## 技术栈

React、TypeScript、Vite、Express、Electron、SQLite 和 Playwright。
